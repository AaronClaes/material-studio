# Material Studio

A node-based texture authoring studio built for 3D workflows. Connect processing nodes on a canvas to build pipelines for generating and manipulating texture maps.

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- [TanStack Start](https://tanstack.com/start) + [TanStack Router](https://tanstack.com/router)
- [React Flow](https://reactflow.dev) — node graph canvas
- [shadcn/ui](https://ui.shadcn.com), [Tailwind CSS v4](https://tailwindcss.com)
